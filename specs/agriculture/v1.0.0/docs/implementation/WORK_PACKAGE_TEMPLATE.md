# 工作包交付记录模板

每个工作包复制本模板到本目录的工作包记录文件，填实际值。不要把模板条目或计划命令当执行证据。

## 基本信息

工作包、任务ID、阶段、日期和时区、执行人或Agent、分支/提交、相关需求、依赖状态。

## 输入与范围

使用的上游提交、规格版本、环境、样本/来源许可；已有能力与本次新增/修改；不涉及的相邻模块及原因。

## 交付内容

代码路径与关键行为，迁移及回滚，API/事件/Schema变更，前端界面，权限与错误处理，任务/费用/审计关联，配置模板和运维说明。

## 失败、风险与阻塞

准确记录未通过项、复现条件、影响需求、已尝试修复、下一动作。外部缺失列出所需资料/授权/预算及可继续任务；不得伪造通过。

## 状态回填

同步tasks.json与DEVELOPMENT_CHECKLIST.md，更新STATUS与验收矩阵/证据记录。done要求对应实现与必需验证都完成；代码完成但live缺失记录等待验收，不能用done掩盖门禁未通过。

## 续接点

下一任务、依赖、当前未提交改动、运行中的进程/任务、恢复命令与注意事项。无需重新读取或重做已经有可信证据且基线未改变的完成项。
