# 架构与产品决策记录

版本1.0.0，日期2026-10-29。以下为用户已接受的总体方向及本规格为可实施性确定的默认决策；预算、外部付费、生产环境与现场控制仍按具体授权执行。实施发现新的事实时，以追加ADR调整，保留原理由与影响，不静默删需求。

| ADR | 决策 | 理由与约束 | 重新决策条件 |
| --- | --- | --- | --- |
| ADR-001 | 名称WeaveSense-DigitalTwin，独立产品工作区/分支 | 保留原Flow和AgriScope历史；未假设目标GitHub远程存在 | 用户指定目标仓库/名称 |
| ADR-002 | Flow为平台主干，AgriScope为独立GIS领域服务 | 重用身份/Agent/账本及GIS处理，避免双重平台 | 实测证明关键实现不可维护 |
| ADR-003 | Go+Node/Pi/Loom+Python混合运行 | 专业遥感逻辑保留，Go承担业务平台；不为统一语言重写所有算子 | 维护/性能数据证明具体模块需迁移 |
| ADR-004 | 三逻辑库/独立角色/独立迁移 | 单一写入所有者；API+outbox/inbox交互 | 隔离容量需求需拆集群 |
| ADR-005 | 统一会话+短期受限服务身份 | GIS不信任浏览器operator_code；每次对象授权 | 平台现有SSO约束需要等价协议 |
| ADR-006 | 普通DB缺scope默认拒绝 | 消除空scope隐式全局特权；旧系统任务逐项迁移 | 无例外允许靠关闭RLS放行 |
| ADR-007 | 首轮Vue同域/agri子应用，平台React | 优先业务闭环、保持上游可追踪；之后按收益迁高频页面 | 长期维护成本或体验一致性要求 |
| ADR-008 | OpenLayers二维优先，Cesium可选 | GIS编辑与分析优先，三维来源明确 | 真实客户需要设施/地形/3DTiles |
| ADR-009 | 农业生产构建排除tldraw依赖使用路径 | 该依赖非根MIT覆盖；只隐藏菜单不足 | 用户购买适当许可并要求启用 |
| ADR-010 | 农场/稳定地块/种植季为农业核心 | 调查task不能替代跨季经营对象；split/merge留血缘 | 客户复杂土地管理模型需扩展 |
| ADR-011 | PostgreSQL作业账本+outbox，独立worker | HTTP请求不承载长计算；Redis可缓存但非唯一任务真相 | 实测后需引入专门队列/编排器 |
| ADR-012 | 至少一次投递+幂等业务效果 | 跨库不依赖分布式exactly-once承诺 | 仍须保留应用层去重 |
| ADR-013 | 不可变产物+manifest校验+元数据发布 | worker可崩溃、对象写与DB非同事务，需可恢复发布 | 更强存储原语被真实验证 |
| ADR-014 | NDVI变化作监测，模型输出有适用域 | 防止用颜色/模型文案冒充农学验证 | S5真实数据验证后扩大承诺 |
| ADR-015 | 敏感下载走在线鉴权，直签有界撤回 | 已发签名URL不受应用登出直接撤销 | 产品选择全部下载网关以强化撤销 |
| ADR-016 | 预算冻结、整数计量、幂等结算 | 处理取消/迟到/重试/未知provider结果 | 商业计量维度变化需版本迁移 |
| ADR-017 | 套餐价格待试点测算 | 不代替用户决定售价、购买或毛利承诺 | 有真实成本和客户反馈 |
| ADR-018 | 支付provider-neutral，manual_invoice可用于已选择的B2B试点 | 真实到账/独立复核/凭证；自助支付未live不能启用 | 用户选择商户渠道并完成真实验收 |
| ADR-019 | 首版移动Web/PWA | 满足GPS/相机/弱网；不声称微信小程序已实现 | 用户批准独立渠道范围 |
| ADR-020 | S0-S3先达成商用，S4/S5独立门禁 | 传感器、预测和控制依赖真实外部资料 | 数据和现场条件成熟 |
| ADR-021 | 自定义Agent仅授权工具子集，技能版本固定 | 提示词无法扩权；任意脚本需独立沙箱方案 | 已建立代码执行隔离与审批 |
| ADR-022 | 真数据和fixture分层验收 | 不将作者自述测试或截图当live证据 | 无放宽完成状态的例外 |

## 新ADR模板

标题、日期、背景与证据、当前约束、候选方案、选择及理由、对FR/NFR/任务/API/数据迁移的影响、风险、验证计划、回滚方式、需要的外部授权。涉及范围/费用/对外行为的重大变更先给出具体可复核方案，再请求必要决策；普通实现细节在已授权范围内自主推进。
