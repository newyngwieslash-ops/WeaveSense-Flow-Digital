## 状态口径
- **已实现**：代码已合入或在 PR 中。
- **已自动测试**：CI 或本地自动测试覆盖并通过（注明环境）。
- **已真实集成验证**：使用真实 MCP 部署、真实模型、真实 TTS、真实对象存储与真实账本链路验证。目前没有任何一项达到。
- **已人工验收**：由教师、教研或产品负责人按 AC 执行并留存证据。目前没有。
- **待外部条件验证**：缺凭据、部署或真实用户。

mock 或本地测试通过不等于生产验收。
