## 真实闭环

严格 Origin 与 CSRF 负例被拒绝；不能用有效 CSRF 恢复已经撤销的成员权限。旧 cookie 下的高权限写返回权限 403，而不是用 CSRF 失败冒充撤权。真实 PostgreSQL 检查旧授权 decision、已签票据的当前 epoch 以及重新连接后的拒绝行为。

实际浏览器跨越生产 30 秒周期：35038ms、347 次连续采样保持邀请码与未提交草稿；只有观察开始后发起且完成的真实 session/workspaces 请求计入。没有合成生命周期事件或重载页面。未提交撤邀预览在重验后不复活，同邀请码随后接受成功。另通过同进程真实标签隐藏/显示验证降权清理，旧表单和页面所属确认 portal 均消失。
