8. 已解决（W10）：Agent 侧数学工具经平台适配接入，精确内网 MCP 目标白名单已实现；全局公网策略未放宽。真实部署地址与网络策略批准仍待外部条件。
9. 交互图形的参数帧带有点坐标，学生可以据此数值估量（例如弦长随角度的变化）。这属于探索本意，不泄漏精确答案文本，但教师若要求“答案开放前不提供可测量图形”，需要增加按任务关闭交互的政策（待确认问题 9）。
10. 没有 TTS，因此逐步讲解只有静音模式；有声模式待供应商与凭据。

12. 题组每题只能提交一次（ITEM_ALREADY_SUBMITTED），不能修改；单题同构自测保持原行为。
13. 讲解编辑只能改字段（步骤标题、讲解文字、板书、提示文字、读音）；题目、参数、答案、图形与检查题只能通过新的题目修订修改。老师改过的板书不做自动数学验证，只标记为 teacher_edited_not_auto_verified，由审核人逐行核对；讲解文字中写出答案的检查只覆盖提示文字（已有的泄漏守卫），步骤文字本就按答案政策锁定。
14. 讲解编辑器目前只有单元测试与 API 自动测试（E23），没有纳入真实 Chrome 端到端测试；教师页面的人工验收待做。
