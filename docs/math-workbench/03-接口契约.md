# 03 接口契约

## 1. 数学服务（services/math-service）

启动：`python -m mathsvc.server`。环境变量：`MATH_SERVICE_KEY`（≥32 字节，与平台 FLOW_MATH_SERVICE_KEY 相同）、`MATH_DATA_DIR`、`MATH_LISTEN`。

### REST（平台内部适配）
每个请求带 `X-Math-Context: base64url(JSON{tenant_id, actor, purpose, exp})` 与
`X-Math-Signature: hex(HMAC-SHA256(key, ctx_b64 \n METHOD \n PATH \n sha256hex(body)))`。上下文过期或有效期过长时拒绝（POLICY_REVOKED）。tenant 只取自签名上下文，请求体中的 tenant 不被信任。

| 方法与路径 | 说明 |
| --- | --- |
| GET /healthz | 无鉴权；版本与目录版本 |
| GET /v1/catalog | 题族目录与限制 |
| POST /v1/jobs | `{kind: analyze或lesson_build, idempotency_key, problem, problem_hash, …}`；新建返回 202，同键同输入返回 200 原作业，同键不同输入返回冲突 |
| GET /v1/jobs/{mj_…} | 作业视图（schema `edu.math.job/1`） |
| POST /v1/jobs/{id}/cancel | 协作式取消（阶段之间生效） |
| POST /v1/reconcile | `{kind, idempotency_key}` → `{found, job}`；只查询，从不执行 |
| POST /v1/grade | `{expected:{exact, plain}, response, approx:{allowed, rel_tol}, unit_policy}` → `{result, reason, grader}`。同步，在与作业阶段相同的隔离子进程中运行（空环境、资源上限、10 秒超时）。result 取值 correct、correct_approx、incorrect、needs_exact、needs_teacher、invalid。返回值从不包含期望答案。学生文本只经白名单解析，不 eval。区间只接受 `[a, b]`；文字、步骤与证明一律 needs_teacher |
| GET /v1/artifacts/{ma_…} | 产物正文；头部 X-Artifact-Sha256、Audience、Kind |

### MCP（Streamable HTTP，POST /mcp）
Bearer 令牌由平台签发（edumath.MCPToken，带租户与过期时间）。工具：math_analyze_start、math_lesson_build_start、math_media_render_start（未配置供应商时返回 PROVIDER_UNAVAILABLE）、math_job_get、math_job_cancel、math_call_reconcile、math_artifact_get（HTML 与媒体不进入模型上下文，只给元数据）。幂等键可放在参数或 `_meta.idempotency_key`。已用 Go MCP SDK v1.6.1 客户端验证（TestMCPProtocolWithGoSDK）。

### 作业视图
`{schema_version, job_id, kind, status, stage, progress, seq, result_refs[{artifact_id, kind, audience, sha256, media_type}], usage[{stage, unit: compute_ms, quantity}], warnings, error{code, message, retryable, next_action}}`

状态：queued、running、needs_confirmation、succeeded、failed、cancelled、reconciliation_required（平台侧）。阶段：validate_input、solve、verify、compose_lesson、project_student、render_preview。

产物：solution 与 validation_report（teacher）、lesson（teacher）、lesson_student（student）、preview_html（teacher）、preview_html_student（student）。

### 错误码
| 代码 | 可重试 | 下一步 |
| --- | --- | --- |
| INPUT_AMBIGUOUS | 否 | 教师确认输入 |
| CONDITION_CONFLICT | 否 | 修正条件 |
| UNSUPPORTED_FAMILY | 否 | 人工编写 |
| PARAMETER_LIMIT | 否 | 调整参数 |
| METHOD_MISMATCH | 否 | 更换方法配置 |
| VALIDATION_FAILED | 否 | 教师复核 |
| RENDER_FAILED | 是 | 重试渲染 |
| BUDGET_EXCEEDED | 否 | 提高预算 |
| RATE_LIMITED | 是 | 稍后 |
| PROVIDER_UNAVAILABLE | 是 | 稍后 |
| OUTCOME_UNKNOWN | 否 | 对账 |
| REVISION_CONFLICT | 否 | 重新加载修订 |
| POLICY_REVOKED | 否 | 联系管理员 |
| TIMEOUT_UNDETERMINED | 否 | 简化或人工（不等于无解） |
| INTERNAL | 是 | 稍后 |

## 2. 平台 API（/api/edu，edumath.API）

教师、审核员、机构管理员：请求带 X-Workspace-Id（空值表示个人工作区）且需有对应教育角色。学生：请求带 X-Edu-Tenant 且有 student 绑定。

| 方法与路径 | 角色 | 说明 |
| --- | --- | --- |
| GET /edu/me | 任意 | 当前教育角色 |
| POST /edu/roles | 租户 owner/admin 或 org_admin | 只能授予教职角色；学生经邀请加入（待做） |
| POST /edu/problems | teacher | 创建题目与首个修订 |
| POST /edu/problems/:id/revisions | teacher | 乐观并发（latest_revision），冲突返回 REVISION_CONFLICT |
| POST /edu/problem-revisions/:id/confirm | teacher | 绑定 input_hash |
| POST /edu/problem-revisions/:id/analyze | teacher | 需已确认；Idempotency-Key；立即返回作业 |
| GET /edu/jobs/:id；POST /edu/jobs/:id/cancel；POST /edu/jobs/:id/reconcile | 教职 | 查询、取消、对账 |
| GET /edu/solution-revisions/:id | 教职 | math_state 与证据 |
| POST /edu/solution-revisions/:id/lesson | teacher | 需 math_state=verified |
| GET /edu/lesson-revisions/:id | 教职 | 课件修订 |
| POST /edu/lesson-revisions/:id/review | reviewer 或作者（self_allowed） | 绑定 lesson_hash |
| POST /edu/lesson-revisions/:id/publish | teacher | 需批准记录与 hash 一致；不可变、幂等 |
| GET /edu/artifacts/:id/url | 有权者 | 签发 ≤5 分钟的签名链接 |
| GET /edu/student/assignments、/:id | student | 只返回学生投影与学生预览链接 |
| GET /edu/files/:id?… | 签名持有人 | 取件时复核权限（含监护人同意）；CSP sandbox；no-store |
| GET/POST /edu/classes | teacher 或 org_admin | 列出本人任课班级（管理员看全部）；创建班级，创建者自动任课 |
| POST /edu/classes/:id/teachers | 租户 owner/admin 或 org_admin | 指派持 teacher 角色且为工作区成员的教师 |
| POST /edu/classes/:id/invites；…/invites/:inviteId/revoke | 该班任课教师或 org_admin | 返回一次性展示的 `<id>.<secret>`；默认 7 天、60 次，上限 14 天、200 次 |
| POST /edu-join | 任意登录用户 | 不经租户中间件；系统上下文定位邀请、常量时间比对密钥，在邀请所属租户事务内授予学生角色与选课；被撤销角色或已退班的学生不能凭码恢复（403） |
| GET /edu/classes/:id/roster；POST /edu/enrollments/:id/withdraw | 该班任课教师或 org_admin | 名单仅含选课 ID、学生 ID、状态、同意状态 |
| GET/POST /edu/classes/:id/assignments；POST /edu/assignments/:id/withdraw | 该班任课教师或 org_admin | 只能分配同一工作区已发布的发布版 |
| POST /edu/consents | 租户 owner/admin 或 org_admin | `{studentUserId, status: granted或withdrawn, evidenceRef}`，授予需证据编号 |
| GET/PUT /edu/policy | 读：教职；写：管理员 | reviewMode、consentMode；设为 not_applicable 需填写理由并审计 |

### 学生学习（PR #53 起，learn.go）
| 方法与路径 | 角色 | 说明 |
| --- | --- | --- |
| POST /edu/classes/:id/assignments 新字段 | 任课教师 | startsAt、dueAt（RFC 3339，须带时区，入库为 UTC）、allowLate、answerPolicy（after_submission、after_due、teacher_release，默认 teacher_release）、approxAllowed、unitPolicy（required 或 optional）。after_due 必须有 dueAt；dueAt 必须晚于 startsAt |
| GET /edu/student/assignments/:id/learning | student | 政策、本人作答、已解锁层级、自测状态（提交后才含自测答案）、复习项 |
| POST /edu/student/assignments/:id/attempts | student | `{item: main或check, kind: answer或no_idea, response, clientKey, reviewItemId?}`。clientKey 8 至 64 位，同键重放返回原记录；空白记无效；与上次相同记 duplicate；首个有效主题作答冻结为 firstValid；判分失败记 undetermined 而不是错；未开始 403 NOT_STARTED；过期且不允许补交 409 ASSIGNMENT_CLOSED |
| POST /edu/student/assignments/:id/hints | student | `{level: 1..5}` 只返回该层。须按序解锁（HINT_ORDER）；第 4 层须先作答或选择没有思路（HINT_GATED）；第 5 层为完整解答，按答案政策开放（ANSWER_NOT_RELEASED）；第 1 至 4 层文本经答案标记守卫；自测进行中请求提示即标记该次自测非独立 |
| POST /edu/student/assignments/:id/selftest/start | student | 返回变式题题面（不含答案）；只能提交一次；记录开始前是否看过原题完整解答 |
| GET /edu/student/review | student | 待复习项；+1 天、+3 天、+7 天；必须带 reviewItemId 重新作答才推进，打开旧答案不推进 |
| GET /edu/student/progress | student | 每个任务首答、自测、作答次数；独立自测结果少于 3 个时 evidence 为 insufficient，不给正确率；自测标为 isomorphic_variant（近迁移） |
| GET /edu/assignments/:id/attempts | 任课教师或 org_admin | 全班作答、提示解锁、自测 |
| POST /edu/attempts/:id/judge | 任课教师或 org_admin | `{result: correct或incorrect或partial, note}`，与自动结果并存，不覆盖 |
| POST /edu/assignments/:id/release-answer | 任课教师或 org_admin | 公布完整解答（teacher_release 政策） |

学生访问被同意门阻断时返回 403，错误码 `CONSENT_REQUIRED`，next_action 为 contact_institution。

## 3. 结算契约
- 根预留键 `edu:job:<job_id>`；阶段子预留 `edu:stage:<job_id>:<stage>`；每阶段唯一 EduStageRun。
- 用量类型 `math_compute_ms`，数量为阶段计算毫秒；RecordUsage 只记录，不重复扣费。
- 终态：成功、失败、取消均按已发生阶段结算，剩余释放；reconciliation_required 保持预留，直到对账。
