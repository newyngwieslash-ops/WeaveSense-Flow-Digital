## 单次真实链

`TestIdentityBrowserGISWriteChain` 及四个必需子项全部通过、无跳过。真实 Chromium 经生产 Nginx 模板加载 React 登录表单，以真实账号密码登录，通过会话中间件、平台资源授权、签名 HTTP、Python 验签/请求资源提取/归属检查/当前权限回查/持久 nonce，再调用原 WorkbenchService 的实际写方法和内部提交。

使用两个租户、三个工作区的明确 fixture 归属事实，不从签名声明反向生成领域归属。成功写入仅改变目标工作区对象；另两个范围保持不变。历史版本和审核快照保留，新增操作和稳定审计主体等于该浏览器会话用户。授权撤销后沿用同一浏览器 cookie，再次请求被权限拒绝，而非 CSRF 错误。

浏览器 15 项断言通过，观察到 42 个请求、内部凭据或外部请求违规为零。跨租户、同租户不同工作区、伪造用户/租户/operator 参数、缺 CSRF、跨 Origin 以及降权后写入均被拒绝。Go 侧分别比较全部三个范围的领域表、历史与审计快照；匿名治理入口还比较全部隔离租户的十张平台治理表，避免仅检查 GIS 而漏掉平台副作用。安全 nonce 可以被消费，不将安全记录变化错误等同业务副作用。

## 失败保留与修复

首轮源码 `6c535e6b` / scaffold `9f6c903f` 的整链在登录阶段失败，仅两个前置断言通过，四个必需子项未运行。原报告没有记录 HTTP 503；源码诊断发现测试组合遗漏真实 main 的 `ConfigureRuntime` 初始化，不能把推断补写成原报告观察值。
