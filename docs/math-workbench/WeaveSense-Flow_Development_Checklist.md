# WeaveSense-Flow 数学教研与学习工作台：完整项目开发清单

版本：1.0　日期：2026-10-26　依据：所附《PRD(6).md》v1.0。

本文是可进入任务系统的实施拆分，不代表代码已实现或验收已通过。仅依据附件制定，未重新访问两个仓库；PRD中的已有实现是待实施团队复核的基线。新增的任务顺序、职责与接口资源分组属于实施建议，最终落点以当前仓库为准。原PRD的优先级、支持范围与发布门槛不变。

## 1. 使用方法与完成规则

每个 DEV 编号为可分配工作项；分解后的子任务可使用 DEV-xxx-01 编号。需求追踪附录中的 FR/NFR/AC 是原PRD合同，开发任务不能替代这些合同。全部勾选框初始均未完成。

任务系统建议字段：任务ID、标题、W包、P级、关联需求、关联AC、负责人、前置任务、状态、预计/实际工时、代码提交、测试/评审证据、发布开关、阻塞原因。状态使用待开始/进行中/待评审/待验收/完成/阻塞；需求取消或变更必须另有决策记录。

完成一个任务需要：实现可用；相关正常、拒绝和异常路径验证；权限与版本/费用语义一致；必要迁移和操作说明齐全；有可定位的提交和证据。模拟器测试只支持开发完成判断，不替代真实供应商和正式验收。涉及数学结论的任务由数学负责人审阅；涉及未成年人数据的流程在使用真实学生前完成授权准备。

角色缩写：PM产品/项目负责人；BE Go平台后端；FE前端；MS数学服务开发；ME数学教研负责人；QA测试；OPS运维；DG数据/业务责任人。一个人可兼任多个角色，但不能绕过机构双人审核策略或独立金标准复核。

## 2. 范围、依赖与阶段交付

| 阶段 | 必须交付 | 进入/退出条件 |
| --- | --- | --- |
| G0 | 基线复核、教育模型、角色/答案政策、六题族目录、接口和数据边界 | W0决策冻结；明确客户课程匹配、来源及验收口径 |
| G1 | 一个题族的真实分析→静音预览→受权取件，长任务恢复与正确结算 | 真MCP/模型/对象存储；参数与容量限制冻结；只代表技术可行 |
| G2 | 六题族及教师学生完整P0内测 | 退出须AC-01至AC-60全部通过、六族准入、真实学生授权准备完备 |
| G3 | 机构真实教学试点 | 进入前完成P0；持续4教学周，结束取得AC-61，不能提前伪填 |
| G4 | 扩展发布及P1/P2 | 单位经济、复用与支持能力可证；每个新增能力独立验收 |

关键路径：W0契约 → W1教育身份/修订与W2数学内核 → W3恢复/预算/资产 → W4教师审核发布与W5学生投影学习 → W6媒体/治理 → W7全量准入 → G3试点。W1、W2可在契约冻结后并行；W3可先用契约模拟器；W4/W5同迭代设计并交付；媒体可与后期学习功能并行。权限、来源、数据治理与评测从W0持续执行，不等到最后补齐。

P0包含可选TTS与MP4能力：“可选”表示用户可以不生成，不能解释成开发不交付。首版不包含学生开放聊天、小程序、任意代码工具、全题型求解或无人审发布。

- [ ] **DEV-010 建立评测和金标准计划**：分配240冻结案例与每族建议至少100组参数回归；确定双人争议复核、来源/推导分支分组、盲测保密及严重度规则。
- [ ] **DEV-011 确认基础设施与供应商方案**：复用现有队列/数据库/凭据/账本，确定数学Worker、私有对象存储、渲染隔离、模型/TTS地域准入；无需更换Go主后端。

## W2. 数学服务、验证证据与有限变式

责任：MS/ME/BE。前置：W0 Schema与能力目录；正式调用接W1确认题意。关联：FR-M01–M07、FR-S07、FR-A04、FR-Q01–Q03；AC-06–16、22、27、43、59。

- [ ] **DEV-029 搭建数学服务与隔离Worker**：固定依赖与版本，提供类型化服务入口、健康检查和受控算子；限网络/目录/CPU/内存/耗时，进程不继承平台密钥。
- [ ] **DEV-030 实现受限表达式AST**：仅允许整数/有理数/受限根式和白名单运算；检查深度、节点、数值范围、除零；禁止eval/new Function及模型生成任意Python。
- [ ] **DEV-031 实现题目归一化与准入路由**：输入确认状态、对象/条件/所求/单位/方法；点名重写、左焦点、平移旋转未独立准入时拒绝，不能以文本相似度套题。
- [ ] **DEV-032 实现SOLID-VOL-01**：正交长方体三正边长、单位换算、精确体积及量纲；缺边、斜棱柱、非正长度拒绝；图形与答案用同一数据源。
- [ ] **DEV-033 实现SOLID-ANGLE-01**：仅正方体A1C与底面ABCD夹角及正弦；检查构型、棱长正性、线面角类型、课程允许的坐标/向量法及比例不变性。
- [ ] **DEV-034 实现SOLID-ANGLE-02**：正四棱锥底边a、高h、E为PC中点，BE与PAC夹角正弦；覆盖正参数、特殊比例、非中点/非正棱锥/其他所求拒绝。
- [ ] **DEV-035 实现CONIC-CHORD-01**：标准椭圆a>b>0与右焦点弦；精确范围、水平/竖直端点、两个实交点及可达性；圆/不合法参数/其他焦点不放行。
- [ ] **DEV-036 实现CONIC-SLOPE-01**：标准椭圆P=(a,0)，A/B中心对称的斜率积；检查双斜率有定义，左右顶点禁用；交互到禁点时停止展示定值。
- [ ] **DEV-037 实现CONIC-PARABOLA-01**：固定y²=2px、p>0与顶点O，焦点弦OA·OB；参数约定可见，轴向退化和非两有限实交点拒绝。
- [ ] **DEV-038 实现解状态与独立验证报告**：区分唯一/多解/无解/欠定/不支持/无法判定；超时不写无解；验证假设、等价步骤、边界、可达性与误差，抽样不冒充证明。
- [ ] **DEV-039 实现方法约束与人工课件路径**：禁向量课程返回METHOD_MISMATCH而不换词伪装；目录外可人工审校但明确未自动验证，禁用依赖自动题族的评分/变式。
- [ ] **DEV-040 实现有限变式与检查题生成**：记录母题和变化类型；逐题验证可解性、答案、方法、难度并待教师审；自测避开已曝光题，不把换数题称为远迁移。
- [ ] **DEV-041 实现客观答案等价判定**：按受限表达式、单位、约定精度判断正确/错误/无法判定/待复核；证明图片及全证明不以一次模型判断给最终分数。
- [ ] **DEV-042 统一数学版本与图形数据**：公式、答案、图形、提示、字幕、旁白引用accepted数学版本；探索状态单列，参数失效时结论同步禁用。
- [ ] **DEV-043 建立逐族公式审阅与自动回归**：各族合法/非法组合建议至少100组，参考答案独立复核；保存分支、退化、超限、超时与拒绝证据，六族分别出准入报告。

## 4. 业务API与数据实施核对表

下列为资源分组建议，不强制URL或框架。沿用现有Go服务约定，避免另建第二套用户、余额或工作区。数学MCP工具不能替代审核、发布、分班及学生作答API。

| API资源组 | 必须覆盖的操作 | 关键检查 |
| --- | --- | --- |
| 教育身份/机构 | 配置、角色授予/撤销、上下文切换、同意办理 | 范围与有效期，管理员不自动读学生正文 |
| 课程/班级 | 课程配置、任课、邀请、最小名册、选课/退班 | 邀请可撤销、多机构隔离，不授予workspace成员 |
| 来源/题目 | 上传/裁切、权利记录、OCR结果、确认与修订 | 类型解码、题意确认、hash、教材/方法版本 |
| 分析/课件 | 分析、验证查询、保存/比较、局部生成、四视角预览 | base_revision、依赖失效、不同角色内容投影 |
| 审核/发布 | 提交审核、批准/退回、发布/撤回、版本迁移 | 绑定hash、自审政策、不可变发布、明确影响范围 |
| 教学任务 | 分配、起止时间、补交、提示/答案策略、自测配置 | 班级/个人受众、策略服务端执行、版本固定 |
| 学习记录 | 会话、尝试/补交、提示、预测/检查点、自测提交 | 首次冻结、幂等、曝光记录、独立单元禁止提前反馈 |
| 复习/反馈 | 收藏/错题、复习调度、求助报错、归并和回复 | 重新尝试才完成、个人隔离、公开反馈去标识 |

所有业务写入按资源版本及操作语义设计幂等/并发处理；并非把任意更新都当新生成。错误至少含稳定code、可展示说明、retryable和下一步动作，按PRD保留INPUT_AMBIGUOUS、CONDITION_CONFLICT、UNSUPPORTED_FAMILY、PARAMETER_LIMIT、METHOD_MISMATCH、VALIDATION_FAILED、RENDER_FAILED、BUDGET_EXCEEDED、RATE_LIMITED、PROVIDER_UNAVAILABLE、OUTCOME_UNKNOWN、REVISION_CONFLICT、POLICY_REVOKED等分类。

## 6. 全量需求追踪与逐条验收责任

以下保留原PRD每项编号需求的完整文字，避免任务细化时丢失条件。每项须在任务系统关联具体DEV子任务、实现提交和证据；勾选仅在原需求全部满足后完成。无编号条款由前文W包、非功能表、后续清单及AC附录共同覆盖。PRD中P1/P2条款仍标原优先级。

- [ ] **FR-I01 P0**（责任包：W1）：教师通过现有账户体系登录；教育角色绑定真实租户与工作区。班级邀请、学生账户或机构假名账户必须可撤销，短班级码不是永久访问凭证。

- [ ] **FR-I02 P0**（责任包：W1）：学生身份与班级选课关系独立管理，不因加入班级而获得工作区成员资格。机构身份、班级归属、任务受众、内容发布状态和必要同意均由服务端检查。

- [ ] **FR-I03 P0**（责任包：W1）：一个学生可加入多个班级；每次访问确定机构与班级上下文。不同机构之间不默认合并学习画像。教师离职、学生退班或撤回授权后撤销新访问，并保留适当的业务和审计记录。

- [ ] **FR-I04 P0**（责任包：W1）：小团队允许作者本人完成审核，但必须显式执行审核动作并留记录；机构可以要求第二名审核员。角色切换不能自动绕过审核策略。

- [ ] **FR-I05 P0**（责任包：W1）：监护人同意是独立记录，包含主体、范围、通知版本、取得时间与撤回状态。涉及不满十四周岁学生时，未完成必要同意不得进入个人化数据处理流程；不能以教师勾选替代实际授权依据。[R26]

- [ ] **FR-M01 P0**（责任包：W2）：发布版本化的题族目录，包含 family_id、输入约束、所求、允许方法、排除项、求解器版本和测试状态。只有该题族通过准入才显示“支持自动校验”；仓库示例能运行不代表参数题族已经通过。[R11][R12][R13][R14]

- [ ] **FR-M02 P0**（责任包：W2）：题目事实、解答步骤、教学解释与校验证据分开记录。输入状态至少区分待确认、条件充分、条件矛盾；解答状态区分唯一解、多解、无解、欠定、不支持和无法判定。求解器超时不能标为无解。

- [ ] **FR-M03 P0**（责任包：W2）：对支持题族校验定义域、假设、退化条件、单位、精确答案、关键等价变形、边界与可达性。每个检查明确覆盖范围和验证器版本；数值抽样只能标为抽样一致，不能充当恒等证明或全范围证明。

- [ ] **FR-M04 P0**（责任包：W2）：图形、公式、答案卡、提示、字幕与旁白引用同一已接受数学版本。交互超出原题参数时标明探索状态，随之更新有效结论；不满足条件时暂停显示相应结论。透视图上的等长、垂直不能自动成为题目已知。

- [ ] **FR-M05 P0**（责任包：W2）：课程配置限制允许使用的方法。若只得到向量解而当前课程禁止向量法，返回方法不适配；教师可改配置或人工编写其他解法，不能简单删掉向量符号后宣称已变成纯几何证明。

- [ ] **FR-M06 P0**（责任包：W2）：正式发布需要题意确认、无已知阻断错误、数学检查完成或有明确人工审校依据、教学审核及呈现检查通过。超出目录的内容采用单独的教师人工课件路径，明确标记未由数学服务验证，禁用依赖该题族的自动评分/变式；不进入“自动校验已支持”统计。人工审校不允许覆盖已知错误，也不改变自动校验状态。

- [ ] **FR-M07 P0**（责任包：W2）：有限变式逐题检查可解性、条件、答案、课程方法与难度。记录母题关系及变化类型，独立自测题不能直接复用刚展示过答案的原题。仅改数字的题目可测近迁移，但不作为较远迁移证据。

- [ ] **FR-T01 P0**（责任包：W4）：工作台显示我的课件、班级、待审核、学生问题和近期任务；首次进入可用原创示例走通完整流程。示例班级与模拟学习记录明确标识，不能混入真实运营指标。

- [ ] **FR-T02 P0**（责任包：W4）：支持单题文字、公式和 JPG/PNG 图片；初始上传上限为单图 10 MB、最长边 8,192 像素，服务端按实际解码大小检查。多题图片需先选择一题区域；PDF 批量切题列 P1。上传保留来源、使用权说明、原始文件校验值和可撤销引用。

- [ ] **FR-T03 P0**（责任包：W4）：识别结果可编辑，标出疑似字符、缺失条件和图文矛盾；题干、所求、单位和几何关系分别确认。教师确认后才进行正式求解。所有由模型补出的假设必须显式显示，不自动补成已知。

- [ ] **FR-T04 P0**（责任包：W4）：教师选择教学目标、学生已学方法、预计讲解长度和课件风格。时长是生成目标而非保证；默认单题短课件建议 3–8 分钟，可修改。无法满足方法约束时说明原因并保留草稿。

- [ ] **FR-T05 P0**（责任包：W4）：编辑器同时呈现题目、解题步骤、板书、图形、提示、练习、旁白和质量面板。能够修改单段文字或步骤，不要求编辑整份 HTML/代码。提供撤销、自动保存、版本历史和乐观锁；并发冲突提示合并或另存，不静默覆盖。

- [ ] **FR-T06 P0**（责任包：W4）：支持局部重生成并显示影响范围和预计费用。编辑后按依赖失效：改题意/参数使数学解及所有依赖失效；改推理使相关验证、提示与媒体失效；只改术语读音使相应语音/字幕失效；只改版式触发呈现检查。任何变化都创建新修订，审核是否继承由规则显式决定。

- [ ] **FR-T07 P0**（责任包：W4）：教师可分别预览教师讲义、课堂演示、学生学习、独立自测四种视角；预览明确展示任务开放策略。音频默认不自动播放；可静音预览、听局部配音及修正公式读法。首发至少一套稳定板书主题，其余主题在同等质量验收后启用。

- [ ] **FR-T08 P0**（责任包：W4）：审核清单包括题意、数学结论与条件、课程方法、图文音一致、分级提示、自测题和答案释放。审核记录关联精确修订及内容 hash。审核员可退回具体步骤；有已知阻断错误时禁止发布。

- [ ] **FR-T09 P0**（责任包：W4）：发布生成不可变 Publication；默认私有，仅允许指定班级/人员访问。编辑已发布内容创建新草稿，旧任务继续固定旧版。更新已有任务必须显示受影响学生、重新审核并记录迁移；已经有作答的任务不得静默换题或重判。

- [ ] **FR-T10 P0**（责任包：W4）：教师创建班级、设置任课人、邀请学生或导入最少必要的名册，并分配课件及练习。任务支持课堂学习、课后学习、独立自测；配置开始/截止时间、提示上限、完整解答释放时点、补交政策。界面时区明确，服务端存储 UTC 并计算有效权限。

- [ ] **FR-T11 P0**（责任包：W4）：可从授权题库选择练习，或按已准入题族生成有限变式，经审核后加入任务。每份首发课件至少能够配置一道独立检查题；教师可替换为自己的合法题目，自动评分能力按题型单独标识。

- [ ] **FR-T12 P0**（责任包：W4）：班级面板显示未开始、已尝试、提示后完成、独立自测、待教师判断、报错等分布。进入个体记录需具备任课权限。错因是可修正建议，附学生作答证据；不凭一次错误断言学生缺乏某项能力。

- [ ] **FR-T13 P0**（责任包：W4）：将相同课件、步骤和问题类型的求助归并，教师可批量回复或发布经审核的共同说明。系统把内容错误、权限故障与普通学习问题区分优先级，避免每次点击提示都占用教师人工时间。

- [ ] **FR-T14 P0**（责任包：W4）：复制课件到下一班级或另建修订时保留原来源、授权范围及版本关联。支持收藏、按知识点检索、回看使用反馈；跨机构复制需要相应授权，不带走学生数据。已验证资产复用不重复运行付费生成。

- [ ] **FR-T15 P1**（责任包：W4）：题组批处理、多人共同编辑、完整教材映射、更多媒体主题及机构模板审批。每项作为独立增量，不阻塞首版双端流程。

- [ ] **FR-S01 P0**（责任包：W5）：首页仅显示本人当前可访问班级、任务、复习项和教师反馈。支持手机与平板，进入课件前展示学习目标、预计内容及提示政策；不用学生理解 MCP、Token 或 Credits。

## 9. 排期方法与优先实施顺序

单人实施建议：先完成W0 → W1最小教育授权/题目修订 → W2长方体一族 → W3真实受理/恢复/资产/预算结算 → 最小静音预览，取得G1；再补齐其余五族、结构化教师编辑/审核/发布与学生尝试/提示/自测；继续复习反馈、媒体、机构治理和完整评测。权限与账务应随每段闭环交付，不能最后拼接。

多人实施可按角色在契约冻结后同步推进W1、W2及W3框架，FE同时做教师/学生视图与契约联调；真实数学接口完成后替换模拟器。实现任务的并行不意味着可以并行修改同一领域契约而不评审。

估算在每任务拆至可独立评审后进行，分别登记开发、数学审阅、测试、基础设施与集成工时；外部采购、内容授权、独立评测和四教学周试点列为等待/日历依赖。未确认团队规模和现有代码差异，不给固定周数或发布日期。若减少题族仅可缩小G2内测，不得把不足六族写为完整MVP。
