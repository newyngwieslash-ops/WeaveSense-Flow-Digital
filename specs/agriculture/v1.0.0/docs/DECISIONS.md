## ADR-029：农业浏览器来源与会话绑定防伪（2026-10-30）

DT015 承接 DT014 已验证的同域入口。原平台 CORS 接受 forwarded-host、通配符和
本地回退，Cookie Secure 依赖代理头；这些旧行为保留在未启用农业的影视 profile。
农业启用时必须提供规范外部 origin、私有共享 CSRF key-file；仅明确开发开关允许
literal-loopback HTTP，不根据浏览器头推导部署权威。缺配置拒绝启动。

遵循 DATA_API_CONTRACTS §1.5：采用唯一精确 Origin 加会话 Cookie 域分离 hash token，
而非仅 SameSite/Origin。匿名登录使用有服务端过期验证的随机 preauth nonce + HMAC；
不是第二套账号/登录系统。所有平台副本挂载同一用途隔离的 32-byte key，以支持非粘性
负载均衡及重启；不复用 Flow/Loom JWT、GIS Ed25519 或设置加密 key。
key 轮换仅拒绝旧匿名 nonce，不自行撤销数据库会话。key 不由前端、LLM 或请求提供。

范围涵盖共享认证写、农业写及其他携会话 Cookie 的 API 写；内部服务签名回调不因此
获得绕过授权。独立审计发现 LinuxDO 全局 state+PKCE 没有发起浏览器绑定；农业 profile
暂闭 start 和两个 callback alias、隐藏 provider advertisement，返回明确 503，不消费
state 或设置会话。原影视 OAuth 不变；农业重新启用需正确浏览器绑定与渠道验收。
拒绝重复 Origin/token/会话 Cookie 歧义。
前端每次写前 fresh token、不重放失败写。认证/成员撤销以后续持久事实检查生效；
已签服务票据仍可能在 30 秒签名期内，不能宣称退出取消所有已开始工作。

影响 DT015、AG-FR-002/004、AG-NFR-001/002；无数据库迁移。新增部署 key-file 配置是
已授权内部工程配置，不代表生产秘密已配置或外部付费授权。测试包括真实 HTTP、共享
key 双实例、持久会话重新打开、CSRF/来源负例、PG 降权与浏览器多标签；各自证据独立。
完整合同和回滚约束见 docs/agriculture/BROWSER_SECURITY.md。回滚应关闭农业入口而非
恢复农业 wildcard/无 CSRF 运行，不改原需求或将未运行验收标为通过。

标题、日期、背景与证据、当前约束、候选方案、选择及理由、对FR/NFR/任务/API/数据迁移的影响、风险、验证计划、回滚方式、需要的外部授权。涉及范围/费用/对外行为的重大变更先给出具体可复核方案，再请求必要决策；普通实现细节在已授权范围内自主推进。

## ADR-030：GIS 全表缺省拒绝与旧全局图斑隔离（2026-10-30）

背景：读取实际 ORM 得到 93 张旧领域表：项目根 1、直接项目 40、仅任务 17、
其他父链 33、全局图斑/版本 2。旧 farmland_plots 只有全局唯一 plot_code，
多个项目可共享同一可变行，不能将任意 TaskPlot 关联当成可信租户归属。

选择：DT017 先完成数据库安全边界，不承诺 93 张表的业务接口可用。全部旧领域表
启用并强制 RLS；只对已由 DT016 实际链覆盖的 9 表授予最小权限和双范围策略，
其余 84 表默认拒绝且撤回运行角色 CRUD。新表默认权限同时撤回，机器清单检查
名称与全部外键，防止后续模型静默遗漏。策略使用精确 restrictive 条件，不能被
旧 permissive true 通过 OR 绕过。扩展参考表根据 pg_depend 的真实归属识别。

新增 agriculture_legacy_plot_ownership，由迁移角色显式绑定唯一 plot_code 的
tenant/workspace/project；普通角色不能自助认领。未绑定或隔离的旧数据仍保留，
但不对业务连接可见。无自动回填、无默认租户；历史共享数据需后续经审核的复制/
隔离和血缘迁移。运行连接只接收可信 Verified 派生的事务局部单租户与工作区范围，
同一连接复用与内部 commit 后必须重新安装范围，不能使用迁移所有者作为默认连接。

替代方案拒绝：给全部旧表按任意父引用自动授租户、以全局 public 方式开放未知表、
放开 ProjectUser UPDATE 迁就旧测试、关闭 FORCE RLS 或使运行角色拥有表。
原四张身份/防重表历史迁移文件不改写；新领域迁移对普通 app 角色叠加 RESTRICTIVE
单租户与工作区条件，旧 ANY 租户列表不能扩大范围。独立审查发现的同租户异工作区
元数据缺口通过此新增迁移与真实负例关闭，而不是作为允许泄漏的例外。
新业务工厂必须验证全部 98 表和运行角色权限，独立身份池不能被描述为领域已准备完毕。
后台 worker 本阶段无领域 CRUD。

影响：DT017、AG-FR-005/006、AG-NFR-001/019。DT019 和各后续领域包在补齐全部父链
一致性、对象授权与负例后逐项开放，当前不是删除既有模块或声称全部业务已完成。
详见 docs/agriculture/GIS_DOMAIN_RLS.md 的 9/84 明确列表与迁移文件。

验证分为明确两阶段：fresh pre-domain 的 DT013 合成 ProjectUser 写审计组件；
post-domain 的禁写且记录不变、跨租户/工作区/未绑定拒绝、真实 Workbench 成功及
真实审计失败回滚，最后再次执行实际浏览器→Go→GIS 签名整链。未执行 PG 项保持
not_run，不用单元测试替代。回滚关闭农业入口并恢复验证过的备份/迁移检查点，
不恢复默认 app CRUD 或关闭 RLS。当前仅授权开发/隔离测试，无生产数据操作或
额外付费、采集、设备授权变更。

## ADR-031：Flow/Loom 缺范围拒绝与固定后台能力（2026-10-30）

背景：旧 Flow/Loom 把空租户范围当作 system；简单删去此分支会使后台扫描、
内部签名回调、组织/邀请 admission 及平台共享 provider 额度逻辑失效。实际调用点
必须逐项迁移，不能通过禁用原有影视、数学、知识任务来宣称隔离完成。

选择：普通连接一律要求可信非空范围；独立 app/migrate/system 数据库身份及连接池。
system 只执行固定、有限分页、最小元数据的 SECURITY DEFINER 发现函数，函数拥有者
为 NOLOGIN/NOBYPASSRLS 的 guard，app/system 不可 SET ROLE 成 guard。迁移所有者
只在一次性迁移入口使用，禁止进入 Web 普通池或整份 runtime 环境文件。

规格要求独立受限角色和不可从 HTTP/Agent 取得的能力，而非强制 OS 进程分裂。
因此允许同进程私有后台调度器持有独立 system 池；handlers/tools/请求上下文不得
获取该对象或选择角色。发现 tenant 后，业务仍走 app 的 scoped 短事务。
独立 worker 进程可以作为部署选项，但不能当作新增任务完成前置。

平台跨租户 provider 额度不通过第二套账本或任意余额修改接口实现。受限数据库
触发器绑定既有 reservation 的插入/终态变化，与既有钱包变更同事务；provider
标识、预留量等关键字段冻结，释放/结算与重复事件保留既有语义和回滚一致性。
Loom 运维全局指标由私有后台采样形成完成快照，HTTP 仅可凭既有运维 bearer 读取，
不能由请求触发无范围查询或获取 system 池；失败/过期返回不可用而不是伪造零值。

边界：此次新改的 Flow 后台 claim/read/settle 与外部网络调用分离。既有数学
Sync/Reconcile 中的 HTTP 轮询/启动/取消，以及部分同步 REST 等待接口仍须单独
登记其原有事务行为；只替换其跨租户发现不等于已消除全产品网络长事务。不得
把保留旧调用链的回归结果写成未来持久计算任务已验收。

影响 DT018、AG-FR-002/004、AG-NFR-001/019。验证包括真实 PG 普通空范围/连接复用、
跨租户、系统函数与表权限负例、provider/钱包同事务回滚及真实旧功能回归。
原历史迁移不改写；新增迁移及显式安装器保留校验和。生产旧卷需在恢复副本核验
角色/所有权并执行受控升级；当前仅开发隔离环境授权。回滚不得恢复空范围 system、
放宽 RLS 或把 owner 密码重新注入 API，应停止受影响入口并恢复已验证检查点。

## ADR-032：GIS 纯引用查询范围与完整聚合保护（2026-10-30）

DT019 依赖 DT013/017，不以 W03 新 Farm 实体为前置。新增 owner-only 的旧 plot 到
已存在 canonical parcel/farm 纯引用适配，无几何、生命周期、公开创建、默认农场
或自动认领。实际 GIS 引用与 Verified 的 typed refs/farm ids 精确相交；未知或
混合越权范围拒绝，不能从票据生成归属事实。

查询边界进入事务级资源范围及 restrictive RLS，而不是仅 ORM 返回后过滤。保留
原 84 个未适配领域关闭，清单覆盖 DAO 和服务直接查询及全部 app 源码变化；新表
和新路由必须审查，关闭状态不算领域业务可用。

完整任务和项目缓存计数不可按“至少一个已授权 plot”返回。专用 NOLOGIN、
NOBYPASS query guard 在精确 tenant/workspace/project 下读取真实关联全集，仅以
布尔证明 any/all。完整 task 行要求 all，部分授权旧写整体拒绝，不能过滤子集后
覆盖全任务进度。受控 security_barrier locator 只开放 id/task_code/project_id，
使合法 bbox/list 查询可在 mixed-task 下正常执行而不产生 RLS 循环。项目全局
progress 无 app 列授权；task 级 review 历史要求 all，parcel 历史沿真实 PlotVersion。

验证要求真实相同坐标跨租户、同 workspace 多 farm、Core/alias/aggregate/history
和未映射/跨父链负例；实际导出源行通过不等于正式导出包或 W03 CRUD 已发布。
生产配置缺归属时拒绝，不启用 fixture provider；数据库角色新增只能由受控 DBA
步骤执行，既有迁移文件校验和不改写。详见 GIS_QUERY_SCOPE.md。

## ADR-033：私有对象走版本化同源网关，不发浏览器存储票据（2026-10-30）

DT020 选择经鉴权网关传输，而不是可转发的对象存储直签 URL。浏览器只选择已验证
工作区、对象 ID 和整数版本；Go 从真实会话派生租户，先以专用只读服务能力取得最小
资源引用，再执行现有 Authorize 并签发固定内部请求。GIS 清单不充当权威归属，需
独立 provider、精确资源版本和当前权限；未配置真实 provider 时保持关闭。

清单是 immutable bytes reference，不新增资产或报告生命周期权威。app 只读、worker
无权限；owner 登记的同版本只能撤回，内容变更必须新版本。短票据最长30秒，字节读取
之后再次核对当前清单、权属和权限，拒绝新访问不等于追回已发送/保存副本。
所有成功和失败禁止缓存；PNG/JPEG/WebP/AVIF 可在 CSP/nosniff 下内联，其他类型
强制二进制附件，不透传上游缓存、Cookie、跳转或凭据。

本地 provider 上限64 MiB，逐路径 no-follow、校验长度及完整SHA。大文件/S3、瓦片
生成、影像产品登记和正式报告发布仍由后续工作包交付，不能以本组件冒充完成。
受控测试真实平台会话与签名HTTP、GIS PostgreSQL和实际文件；测试用独立权属事实
不在生产配置开放。原错误签发依赖宿主时区的问题统一转UTC修复，验签严格性不变。

## ADR-034：后台授权快照与短期执行身份分离（2026-10-30）

DT022 保存主体/租户/工作区/资源版本/farm集合/输入hash/权限版本的不可变快照，
不保存请求票据、不创建第二套队列。可信平台调度组合对持久快照重新执行 Authorize，
每个 claim/read_input/publish 检查使用新短票据；浏览器或普通worker不能选择签发主体。
GIS 对照持久快照、独立当前资源事实和实际执行租约，反向平台再做当前授权，不把
仅相同epoch等同仍有效的自然到期授权。权限、资源版本或farm集合变化采取保守拒绝。

GIS 两个新侧表采用精确scope强制RLS与append-only。worker只读快照并追加检查记录，
不能创建/修改快照，既有领域CRUD不扩大。等待数据库锁后、提交前再次检查票据与
当前授权期限，跨有效期的创建/检查整体回滚；长计算和网络调用不持数据库事务。

实际队列尚由W06提供，默认执行provider缺失返回503。当前成功检查是有界元数据，
不是任意结果写权限。W06发布仍必须在真实发布事务内原子验证fencing/CAS；本组件
不声称跨数据库检查与业务发布天然原子或exactly-once。真实PG lease fixture与Go
授权/签名HTTP证明身份链，不替代生产队列、真实影像、取消计费或故障恢复验收。

## ADR-035：农场初建治理与显式业务授权分离（2026-11-01）

DT025依赖DT024真实验收完成后开始。初建农场不存在可用于授权的GIS事实，不能伪造ownership或将空scope当系统。初版owner/tenant_admin可发起workspace创建治理；必须显式选择已有合适业务角色的初始grantee及精确能力，不自动授予创建人/所有者内容权限，不暗改角色。新增farm.archive能力仍受farm_manager角色上限与显式grant约束。

创建采用独立短期workspace-operation签名合同，GIS回查平台当前创建意图/权限；普通business票据非空farm范围规则不变。复用flow CommandDispatcher并通过中性adapter扩展GIS，不新增调度循环；GIS事实/receipt/outbox与平台意图/inbox/grants分库持久，至少一次与业务去重、fencing CAS保证可恢复。201表示两端完成；新增202持久pending明确表达未知/待登记，不伪称跨库回滚。重复created不得复活已撤授权。

区域目录采用版本化部署JSON，未配置明确失败，不默认黑龙江/RS；第一输入profile只接受显式WGS84/CRS84经纬序，其他CRS明确拒绝，通用转换留后续导入任务。权威面积为PostGIS椭球m²，保留版本/来源，演示标识不可升级正式。具体实施合同见项目 `docs/agriculture/FARMS_CONTRACT.md`。新增路由、真实双PG与浏览器恢复负例均须纳入原隔离gate；本ADR不标记尚未实现任务完成。
