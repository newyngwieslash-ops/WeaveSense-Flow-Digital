## 范围与效果

93 张旧领域表、4 张身份表及 1 张显式地块归属表启用 FORCE RLS；未知归属不回填，未知模型或权限漂移拒绝启动。9 张支持实际 Workbench 闭环的旧表按明确能力授予最小权限，其余 84 张默认关闭，不能据此宣称所有领域功能已可用。

项目与全局地块通过可信、独立管理的映射确定租户/工作区。原跨项目共享地块不能猜测归属或静默复制。精确单租户与工作区 restrictive 策略覆盖身份元数据，旧 permissive 策略不能扩大范围。缺少 scope、多租户拼接、同租户不同工作区、未绑定地块及不一致父引用均有负例。

实际同一数据库连接 PID 在不同租户/工作区复用、内部提交后重新开始、回滚及异常清理均被验证。正式领域工厂不回退旧裸连接或迁移 DSN；迁移身份不能作为应用身份。后台独立 `flow_geo_worker` 无继承、无 BYPASSRLS、无领域表 CRUD；当前没有凭空提供跨租户调度权限，后续任务只能通过另行实现的受限接口授权。

当前 schema 下，ProjectUser 写入明确拒绝且原记录不变；真正的 Workbench 写入、稳定主体审计和故意审计失败后的业务/历史回滚均通过。正式部署入口见 `GIS_MIGRATION_COMMAND.md`，角色与默认拒绝清单见 `GEO_DATABASE_ROLES.md`、`GIS_DOMAIN_RLS.md`。
