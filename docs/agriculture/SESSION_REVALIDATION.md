# 农业页面会话与撤权展示边界（DT015）

浏览器中的用户、工作区和能力只是服务器响应的展示投影。BroadcastChannel 或 storage
事件不提供身份、租户、角色和权限，只接受固定版本的失效提示和随机事件编号。
提示不包含秘密、CSRF token 或对象编号，也不能替代服务器授权。

## 清理与重验

- 收到跨标签失效提示、聚焦、页面恢复和 history 回退时，旧投影失效，再请求可信会话及
  工作区。页面隐藏时立即清理受保护内容，回到可见状态才重新加载。
- 可见页面每 30 秒启动一次安全重验，用于不同账号、设备或服务端管理操作导致的撤权。
  这是正常运行浏览器的刷新周期，不是硬实时上界、服务端授权缓存或允许旧请求继续写入的窗口。
  浏览器冻结/休眠不能保证墙钟调度；恢复事件先清理再验证。网络失败时保持拒绝展示。
- React 和 Vue 都用代次检查阻止旧请求晚到复活旧账号。农业查询缓存在强制重验时清除，
  同一用户 ID 的成员关系变化不能复用先前权限投影。已匿名的登录/注册表单保留挂载，
  重验不能无故丢失输入。
- 组织页卸载时销毁自己创建的确认弹窗，先清除预览内容，避免关闭动画遗留旧对象信息。
  不调用全局 destroyAll；旧 controller 已销毁，不允许旧确认回调继续提交。

## 例行检查与输入连续性

30 秒例行检查不再无条件卸载页面。初次可信会话和列表、以及页面已接纳的真实列表
建立展示基线；基线登记绑定发起时的会话代次，迟到的旧账号响应不能替换它。
每次例行检查重新读取会话和工作区，严格比较账号 id/role/status、工作区集合及服务端
`authorityFingerprint`。缺失/格式错误、账号或权限变化、网络失败或 20 秒检查截止均
进入强制清理流程。检查期间禁止新的业务操作并关闭旧确认预览；不把摘要提交为授权。

摘要仅说明当前平台授权输入，不证明 GIS 资源所有权，也不是撤权缓存。它不包含无关的
邀请审计序号，所以创建邀请码不会因为纯审计变化丢失一次性回执。相同权限时 React
保留组织页和输入；成员列表单独从服务器重新读取，保留未改变行的对象和角色草稿，
成员变化使旧确认预览失效。Vue 保留相同可信投影对象。提示/隐藏/恢复事件仍立即强制清理。

组织写入持有页面业务活动租约直到响应、一次性回执及其可信刷新全部处理完；例行检查
等待活动结束再比较（同样受检查截止限制），不能在 CSRF 请求或写后刷新之间丢失结果。
这只是 UI 并发协调，不是后台任务租约或授权机制。服务器每次写入仍实时校验权限。

## 写请求

农业 React 入口才安装现有 HTTP 客户端的安全拦截器，影视入口不安装。
每次写入先同源 GET `/api/auth/csrf` 获取当前会话绑定的 64 位十六进制 token，
通过 `X-CSRF-Token` 发出本次写入。Vue 退出使用同样契约。
不缓存 token、不写入 storage、不放入广播、URL 或日志，不自动重放失败的业务写。
获取失败或格式异常时不发送业务写；响应及错误配置中清除临时 token header。
服务端仍需检查可信 Origin、CSRF、当前会话、成员关系和对象授权；UI 隐藏不构成授权。

## 验证范围

单元测试覆盖秘密字段提示拒绝、重复提示、清理监听器、匿名表单保持、旧响应晚到、
同用户权限缓存清除、隐藏页面不后台恢复身份、CSRF 失败不写入及确认弹窗作用域。
真实浏览器用例在生产 nginx + Go + React/Vue 流程中验证多标签退出/重登录；
无 CSRF 和伪造跨站 Origin 用例由真实 HTTP fixture 发出，不声称浏览器能任意改写 Origin。
独立组织流程验证已降权会话的旧高权限 POST 返回 `403 / forbidden`，不能把
CSRF 失败当作撤权验证。真实 CI 结果须另附新提交对应报告，DT014 的历史通过结果
不自动覆盖 DT015；这些本地 fixture 也不是 PostgreSQL RLS 或真实农场验收。
